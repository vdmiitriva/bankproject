# BankProject

Приложение для анализа банковских операций из Excel-файла. Проект формирует данные для главной страницы, выполняет поиск транзакций по описанию и категории и рассчитывает средние расходы по дням недели.

## Реализованные функции

### Главная страница

Формирует данные для главной страницы на основе даты и времени, переданных в формате `YYYY-MM-DD HH:MM:SS`.

- Приветствие в зависимости от времени суток.
- Сводка по банковским картам: последние четыре цифры номера, общая сумма расходов и расчётный кешбэк.
- Пять операций, отсортированных по убыванию суммы платежа.
- Дата, сумма, категория и описание каждой операции.
- Курсы валют, полученные через API Центрального банка России.
- Цены акций, полученные через Alpha Vantage.
- Фильтрация операций с первого дня указанного месяца по переданную дату включительно.
- Обработка ошибок внешних API: если получение курсов валют или цен акций завершается ожидаемой ошибкой, остальные данные главной страницы продолжают формироваться. Ошибки записываются в журнал, недоступные данные возвращаются пустым списком.

### Простой поиск

Функция поиска находит все транзакции, в описании или категории которых встречается введённая строка.

Поиск не учитывает регистр букв и возвращает все подходящие операции в виде списка словарей, совместимого с JSON.

### Отчёт по дням недели

Отчёт рассчитывает средние расходы для каждого дня недели за последние три месяца относительно указанной даты. Если дата не передана, используется текущая дата.

Результат сохраняется в файл `spending_by_weekday.csv`.

## Установка

Для работы с проектом необходимы Python 3.14 и Poetry.

Клонируйте репозиторий:

```bash
git clone https://github.com/vdmiitriva/bankproject.git
cd bankproject
```

Установите зависимости:

```bash
poetry install
```

## Настройка

### Данные транзакций

Файл `data/operations.xlsx` содержит исходные данные для анализа и входит в репозиторий.

### Валюты и акции

В файле `user_settings.json` укажите валюты и акции, которые необходимо учитывать.

Пример конфигурации:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

### API-ключ Alpha Vantage

Для получения цен акций необходим API-ключ Alpha Vantage.

Создайте файл `.env` на основе `.env_template` и укажите свой ключ:

```env
ALPHA_VANTAGE_API_KEY=your_api_key_here
```

Не публикуйте файл `.env` и не добавляйте реальные API-ключи в Git.

## Запуск

Запустите приложение из корневого каталога проекта:

```bash
poetry run python -m src.main
```

Команда загружает транзакции, выводит количество операций и показывает список доступных функций. Это демонстрационный запуск проекта.

## Тестирование

Запустите все тесты:

```bash
poetry run python -m pytest -q
```

Тесты проверяют бизнес-логику, обработку данных, работу с внешними API с использованием моков и обработку ошибок.

## Проверка качества кода

Проверка форматирования:

```bash
poetry run black --check src tests
```

Проверка порядка импортов:

```bash
poetry run isort --check-only src tests
```

Проверка стиля кода:

```bash
poetry run python -m flake8 src tests
```

Проверка конфигурации Poetry:

```bash
poetry check
```
